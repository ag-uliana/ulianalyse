## Запуск в VS Code

1. Установите Node.js LTS, если его ещё нет.
2. Распакуйте архив и откройте папку `uliana` через File → Open Folder в VS Code.
3. Откройте Terminal → New Terminal.
4. Выполните `npm run dev`. Устанавливать пакеты через `npm install` не требуется.
5. Откройте http://localhost:3000. После правки сохраните файл и обновите страницу.
6. Остановите сервер сочетанием Ctrl+C.

Не открывайте HTML двойным кликом: переводы подключены как JavaScript-модуль и требуют локального сервера.

## Описание

| Файл | Содержимое |
| --- | --- |
| `dist/index.html` | Структура секций, кнопки и ссылки на соцсети |
| `dist/styles.css` | Цвета, шрифты, размеры, сетка, мобильная версия |
| `dist/translations.js` | Все тексты в объектах `ru` и `en` |
| `dist/app.js` | Переключение языка и вывод контента |
| `dist/favicon.png` | Иконка вкладки браузера |
| `.openai/hosting.json` | Идентификатор существующего сайта и настройки публикации |

Цвет акцента задаётся переменной `--acid` в начале `styles.css`.
Для изменения текста найдите его в `translations.js` и обновите обе языковые версии. Сохраняйте кавычки и запятые; внутри строк с HTML ссылками сохраняйте теги.
Размеры раздела about находятся ближе к концу CSS: в нём более поздние правила уточняют ранние.

Проверка синтаксиса: `npm run check`.
